About AMPUDB

Overview

AMPUDB is a manually curated database of antimicrobial peptides (AMPs) that incorporate unnatural amino acids (UAAs). It collects sequence, bioactivity, and chemical annotation data from the primary literature, with the aim of making UAA-containing AMP data findable, searchable, and reusable.

The database currently contains 349 entries drawn from peer-reviewed publications. Each entry is linked to its primary reference via DOI.

Scope

AMPUDB focuses specifically on peptides in which at least one residue is an unnatural amino acid (UAA) — including D-amino acids, β-amino acids, N-methylated residues, peptoid residues, unusual side-chain modifications, and fatty acid conjugates. Natural AMPs without UAA incorporation are included only as parent sequences for context.

UAA Glossary

All unnatural amino acid codes used in AMPUDB are defined in the UAA Glossary, which lists the full chemical name and classification flags (D-amino acid, peptoid, charge, α-amino acid) for each code.

Data availability

The complete dataset is available for download from the Browse page (CSV button) and will be deposited in a public repository upon publication. The database is updated periodically as new literature becomes available.
