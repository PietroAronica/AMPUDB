How to Cite AMPUDB

If you use AMPUDB in your research, please cite the primary publication (details will be added upon acceptance):

[Authors]. AMPUDB: a database of antimicrobial peptides containing unnatural amino acids. Nucleic Acids Research, [Year]. DOI: [pending]

BibTeX

@article{ampudb, title = {{AMPUDB}: a database of antimicrobial peptides containing unnatural amino acids}, author = {[Authors]}, journal = {Nucleic Acids Research}, year = {[Year]}, doi = {[pending]} }

Data citation

If you download and use the dataset directly, please also cite the data deposit (DOI pending) in addition to the paper.
