UAA Naming Conventions

Version 1.1 — June 2026

1. General Principles

Every UAA entry has one unique short code used in sequences, one preferred full name, and any number of synonyms — all reported on the residue page. The code is chosen to be unambiguous and concise; the name is chosen for clarity and literature precedence.

2. Short Code Format

Standard proteinogenic amino acids use the established three-letter codes (Ala, Gly, Phe, …). All derived codes follow the same capitalisation rule: first letter uppercase, remaining letters lowercase (Xxx format).

✓ Correct✗ Avoid
MeLeuMeLEU
NMeValNMEVAL
d-GluD-GLU
βHisBHIS

Use Arabic numerals for ring position prefixes on non-benzene rings and multi-substituted benzene rings: 3FTrp, 4NH2Pro, 3,5FPhe. For a single benzene substituent, use ortho/meta/para notation (see §5).

3. Stereochemistry

D-amino acids: prefix d- (lowercase d, hyphen) before the code — d-Ala, d-Phe, d-3OHLeu. For other stereocentres, use allo- for diastereomers at non-α positions: allo-Ile, allo-Thr.

4. Peptoids (N-substituted Glycines)

Peptoids carry their sidechain on the nitrogen rather than the α-carbon. Prefix pep- followed by the residue whose sidechain is on the nitrogen. β-Peptoids (N-substituted β-alanines) use β-pep-.

CodeFull NameSidechain
pep-Phepeptoid phenylalaninebenzyl
pep-Leupeptoid leucineisobutyl
pep-Argpeptoid arginine3-guanidinopropyl
pep-4FPheN-(4-fluorobenzyl)glycine4-fluorobenzyl

When the sidechain does not match any standard amino acid, describe it explicitly: pep-6C (hexyl sidechain).

5. Ring Position Notation

Benzene ring — single substituent: use ortho/meta/para: pClPhe, mFTyr, oFPhe.
Benzene ring — multiple substituents: use numbers: 3,5FPhe, 2,6FPhe.
Other ring systems (proline, tryptophan, histidine, etc.): always use numeric positions: 4HypPro, 5FTrp, 4NH2Pro.

6. Sidechain Position Notation (α-amino acids)

Greek letters indicate which sidechain carbon bears a substituent, counted from the α-carbon:

LetterSidechain positionExample
βC3 (first sidechain carbon)βOHPhe
γC4γFAbu
δC5δAva
εC6εLys

This notation applies only to α-amino acids and is not used for ω-amino acids (see §8).

7. N-Methyl and N-Substituted α-Amino Acids

N-methyl L-amino acids: prefix NMe (no hyphen): NMeAla, NMeLeu, NMePhe.
N-methyl D-amino acids: NMe-d-Phe, NMe-d-Ala.
Other N-substituents described explicitly: NMe2Lys, NBnArg.

8. Extended-Backbone Amino Acids

Simple ω-amino acids (no sidechain): Greek letter indicates backbone length (position of NH₂ from carboxyl carbon).

LetterBackbone carbonsExample
β3β-Ala (β-alanine)
γ4γ-Abu (GABA)
δ5δ-Ava
ε6ε-Ahx

Extended backbone WITH sidechain: prefix with backbone Greek letter, then append sidechain using the standard amino acid name — e.g. β-Phe (3-amino-3-phenylpropionic acid), β-Leu.

Sidechain carbon counting for α-amino acids with long chains: count only carbons beyond the α-carbon — 2-aminooctanoic acid (8 total, 6 in sidechain) → C6.

9. Homo- and Nor- Series

Where a traditional name exists (ornithine, phenylglycine, homoserine), always prefer it.

10. β-Amino Acids

Prefix β- before the code: β-Ala, β-Phe, β-Lys. The β-homo analogue of an α-amino acid may also be written βhXxx (e.g. βhPhe).

11. Dehydro Amino Acids

α,β-dehydro: prefix Δ or Dh — ΔPhe, DhPhe, Dha (dehydroalanine), Dhb (dehydrobutyrine). For other positions, indicate explicitly: DHγAla.
